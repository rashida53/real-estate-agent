# Real Estate Agent

Agent-driven full stack application for real estate listings.

## Overview

- **Repliers REST API** — Real estate listings data
- **MCP Server** — Wrapper microservice exposing Repliers as tools
- **LangChain Backend** — OpenAI tool-calling agent
- **React Frontend** — Chat UI
- **Node.js monorepo** — Workspace-based structure

See [plan.md](./plan.md) for architecture, data flow, and implementation details.
